# Aggie Engagement Landing Page

This repository contains the Utah State Athletics Aggie Engagement website.

## Live Website
https://aggie-engagement.github.io/aggie-engagement-landing-page/

## Start Here
New maintainers should begin with [MAINTENANCE_GUIDE.md](MAINTENANCE_GUIDE.md).

- [MAINTENANCE_GUIDE.md](MAINTENANCE_GUIDE.md) - beginner-friendly setup and maintenance instructions
- [PROJECT_HANDOFF.md](PROJECT_HANDOFF.md) - project structure, ownership, and handoff information
- [PROJECT_STATUS.md](PROJECT_STATUS.md) - current project status, handoff progress, and known maintenance items
- [AGENTS.md](AGENTS.md) - instructions for Codex / AI-assisted maintenance

## Website Structure
- `aggie-engagement/index.html` - main webpage
- `aggie-engagement/styles.css` - main stylesheet
- `assets/` - shared website images
- `index.html` - root redirect page; normally should not be edited for routine website updates

## Local Preview
Run:

```text
npm start
```

Then open:

http://localhost:5173/aggie-engagement/

See [MAINTENANCE_GUIDE.md](MAINTENANCE_GUIDE.md) for complete setup instructions.

## Publishing
- Production branch: `main`
- Hosting: GitHub Pages
- Publishing source: `main` / repository root
- Pushing to `main` can update the public website.
- Review and preview changes before pushing.
